# 🏡 Дачагадайка

Интерактивный симулятор угадывания цен на дачи в Ленинградской области.

## 📖 Описание

Дачагадайка — это веб-приложение, которое позволяет проверить, насколько хорошо вы разбираетесь в ценах на дачную недвижимость в Ленобласти. 

### Механика игры

1. **Старт** — на главной странице нажимаете «Запустить игру»
2. **10 раундов** — каждый раунд показывается случайная дача из базы
3. **Угадай цену** — двигаете бегунок и нажимаете «Оценить»
4. **Результат** — видите правильную цену, разницу и заработанные очки
5. **Итог** — после 10 раундов получаете итоговый результат

### Система подсчёта баллов

| Отклонение от реальной цены | Баллы за раунд |
|---|---|
| ±5% | 100 |
| ±10% | 90 |
| ±15% | 80 |
| ±20% | 70 |
| ±25% | 60 |
| ±30% | 50 |
| ±40% | 40 |
| ±50% | 30 |
| ±70% | 20 |
| ±100% | 10 |
| >100% | 5 |

### Категории результатов

| Категория | Средний балл | Описание |
|---|---|---|
| 🌱 **Опытный огородник** | 70+ | Близки к реальным ценам |
| 💰 **Щедрый дачник** | 40–69 | Переплачиваете за недвижимость |
| 🏚️ **Уходи с моей дачи** | <40 | Экономный инвестор |

## 🛠 Технологии

- **React 18** + **TypeScript** — UI
- **Vite** — сборка и dev-сервер
- **Tailwind CSS v4** — стилизация
- **Без тяжёлых библибик** — минимальный бандл (~55 KB gzip)

### Особенности

- 📱 Mobile-first дизайн
- ⚡ Быстрая загрузка, минимальный трафик
- 🔒 Security headers (CSP, X-Frame-Options, Referrer-Policy, nosniff, Permissions-Policy)
- 🎨 Фирменный цвет `#26CD94`
- 🖼 Локальные фото с Unsplash
- 🎬 Анимация бегунка при первом запуске

## 🚀 Запуск

### Разработка

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр продакшен-сборки
npm run preview
```

### Требования

- Node.js 18+
- npm 9+

## 📊 База данных

В проекте 30 объявлений дач в Ленинградской области с реальными характеристиками:
- Разные направления (Приозерское, Выборгское, Московское, Киевское и др.)
- Разные материалы (брус, кирпич, каркас, газобетон и др.)
- Цены от 650 тыс. до 35 млн рублей
- Расстояния от 5 до 130 км от КАД
